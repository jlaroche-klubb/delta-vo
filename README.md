# delta-vo
Delta Services - Gestion VO nacelles d'occasion

## Circuit VNC / prix (août 2026)

Tous les 15 jours : la compta reçoit le fichier VNC (envoi automatique via
Nacelle Expert), le renvoie complété à l'ADV (bouton « Import VNC », page
Disponibles), qui vérifie puis génère l'« Export Pricing PDG » (2 feuilles :
prix à faire / prix à revoir). Les prix décidés par le PDG se réimportent
via « Import Pricing ».
